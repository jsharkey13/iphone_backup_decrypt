# Security Policy

The `iphone_backup_decrypt` library is maintained on a best-effort basis. Only the latest version of the library will be supported.

No guarantee is offered for the security or correctness of the tool; you should review the code before relying on it in security-critical applications.


## Reporting a Vulnerability

You can report a vulnerability securely via GitHub, using the 'Security' -> 'Report a vulnerability' button. Concerns about privacy when using the tool should instead be raised using GitHub Issues in the interest of public discussion.
